# 🎨 My Watercolor Collection - 色見本管理アプリ

水彩絵の具の色見本を管理するWebアプリケーションです。複数のメーカーの色データベースから色を検索して登録したり、手動で色を追加したり、画像から色を自動抽出したりすることができます。

ホルベイン、ウィンザーニュートン、ターナーなど複数のメーカーから色を購入している方が、**すでに所有している色を記録して、買い足す際に色が被らないようにする**ことを目的としています。

## 🌟 主な機能

### 📖 カタログから登録
- **複数メーカーの色データベース対応**
  - ホルベイン（Holbein）- 8色
  - ウィンザーニュートン（Winsor & Newton）- 5色
  - ターナー（Turner Colours）- 3色
  - シュミンケ（Schmincke）- 3色
  - ダニエルスミス（Daniel Smith）- 3色
- リアルタイム検索で色を検索
- 色の詳細情報（顔料コード、堅牢性）を表示
- ワンクリックでマイコレクションに追加

### ✍️ 手動で色を登録
- 英語名と日本語名を指定
- 色を16進数カラーコード（#RRGGBB）で直接入力
- カスタム色をマイコレクションに追加

### 📷 カメラで登録または画像から抽出
- **カメラから撮影**（ブラウザ許可が必要）
  - リアルカメラまたはフロントカメラから撮影可能
  - 撮影結果から自動的に平均色を抽出
- **画像からアップロード**
  - ローカルファイルから画像を選択
  - 自動的に画像の平均色を計算
  - 抽出した色はフォーム内に自動入力されるので微調整も簡単

### 📚 マイコレクション
- 登録した全ての色を一覧表示
- メーカーごとにグループ化して整理
- 登録日時を記録
- ワンクリックで不要な色を削除

### 💾 自動保存機能
- ブラウザのLocalStorageに自動保存
- ページをリロードしてもデータが保持される
- オフラインでもアプリを利用可能

本番環境向けにビルド：

ビルドファイルは `dist/` ディレクトリに生成されます。

## 📖 使用方法

### 基本的な流れ

1. **メーカーを選択** - 最初のビューでメーカーボタンをクリック
2. **色を検索・追加** - 色の名前で検索してクリック
3. **マイコレクションで確認** - 📚 ボタンで登録した全色を表示

### カタログから登録

1. **📖 カタログから登録** ボタンをクリック
2. メーカー（ホルベイン、ウィンザーニュートンなど）を選択
3. 色名で検索
4. **追加** ボタンをクリック
5. マイコレクションに追加されます

### 手動で色を登録

1. **✍️ 手動で登録** ボタンをクリック
2. 色の英語名を入力（例：Cerulean Blue）
3. 色の日本語名を入力（任意）
4. 色を16進数で入力（例：#0080B0）
5. **カタログに追加して登録** ボタンをクリック

### 画像から色を抽出

1. **📷 カメラで登録** ボタンをクリック
2. **画像から抽出** セクションで **Choose File** をクリック
3. 画像ファイルを選択（JPEG、PNG等）
4. 自動的に色が抽出されてフォームに入力される
5. 必要に応じて色名を編集して登録

**ヒント**: より正確な色抽出のために、カラーチャートを一つの色で埋め尽くした画像をアップロードしてください。

### マイコレクションの確認と管理

1. **📚 マイコレクション** ボタンをクリック
2. 登録した色がメーカー別にグループ化されて表示されます
3. **✕** ボタンで不要な色を削除

## トラブルシューティング

### 色が追加されない場合
1. ブラウザのコンソールでエラーを確認
2. ローカルストレージが有効か確認
3. キャッシュをクリアして再試行

### パフォーマンスが低い場合
1. メーカーカタログのサイズを確認
2. 登録済み色数を確認
3. ブラウザのリソース使用状況を確認
